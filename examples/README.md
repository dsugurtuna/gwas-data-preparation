# Synthetic example data

Invented PLINK 1.9 report files for 40 made-up samples (SYN001-SYN040) and 60 made-up variants, with a few planted failures (one low-call-rate variant and sample, two rare variants, one HWE failure, one heterozygosity outlier, one sex mismatch, one related trio), plus two `.bim` files with one flipped, one ambiguous and one incompatible SNP. No value comes from real data.
